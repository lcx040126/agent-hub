# Agent Hub v0.2.8

Agent Hub v0.2.8 修复任务级租约范围事件接口无法通过桌面代理读取的问题，并补充代理路由回归保护。

## 问题修复

- 修复桌面代理未放行 `GET /api/leases/:id/scope-events`，导致租约范围历史在桌面端显示错误的问题。
- 为该接口允许 `limit` 与 `before` 分页参数，同时继续拒绝未知查询参数和任意未登记的 API 路由。
- 增加桌面代理路由回归测试，覆盖成功请求、分页查询和敏感参数拦截，避免服务端新增读取接口后再次出现客户端白名单不同步。

## 兼容性与升级

- 应用版本为 `0.2.8`，协议版本保持 `2`，数据库 schema 保持 `6`，最低来源协议和 schema 保持 `1` 与 `2`。
- v0.2.7 用户应通过应用内更新升级到 v0.2.8；升级不需要重新加入房间，也不会删除房间数据库、连接凭证、Hook 或 MCP 配置。
- v0.2.7 的租约协调、范围审计和历史数据继续兼容；本版本只修复桌面代理访问路径并重新打包完整客户端。

## 已验证

- 桌面代理专项测试覆盖 `scope-events` 路由及 `limit`/`before` 查询参数，并确认未知参数仍被拒绝。
- 版本元数据、服务端健康版本、更新清单测试和打包迁移探针均已切换到 `0.2.8`。
- 发布前仍需由 Windows 发布流水线执行完整 TypeScript 检查、全量测试、NSIS 打包、更新恢复探针、签名清单和安装包校验。

## 尚未完成的真实验收

- v0.2.7 正式安装目录覆盖升级到 v0.2.8、真实租约范围历史界面和双机成员升级仍需在正式发布前独立确认。
