# Agent Hub v0.2.8

Agent Hub v0.2.8 提升 Windows 与 UGit 环境兼容性，修复 Codex Hook 放行提示和租约范围历史读取，并增加异常重启恢复与动态数据分级清理。协议版本保持 `2`，数据库 schema 保持 `6`。

## 新增内容

- 新增统一 Git 可执行文件发现：依次检查显式配置、当前进程 PATH、Git for Windows 标准目录和 UGit 内置 Git，并把解析结果用于项目选择、仓库扫描、Hook 归因、提交证据和任务收尾。
- 新增异常重启恢复状态。旧成员暂停请求尚未到达房间服务器时，已保存房间会显示本机收尾或远程清理阶段、当前服务器地址、重试次数、倒计时和最后失败原因。
- 新增单房间“立即重试”和自动恢复。重试继续复用原有 `requestId`、`cutoffAt` 与幂等清理边界；同一连接不会并发发送重复请求。用户尝试进入的房间在旧清理成功后会自动完成正式激活。
- 新增后台动态数据分级清理：服务启动后执行一次，随后每天执行。普通扫描和无租约归属的 Hook 空范围审计保留 30 天，已结束租约的范围审计保留 90 天，高价值协作审计长期保留。

## 问题修复

- 修复桌面代理未放行 `GET /api/leases/:id/scope-events`，导致租约范围历史在桌面端无法读取的问题。接口允许 `limit` 与 `before` 分页参数，同时继续拒绝未知参数和未登记路由。
- 修复 Codex PreToolUse 允许执行并附带提示时返回无效 `permissionDecision: "allow"` 组合的问题。提示改由 `additionalContext` 传递，不再产生 `unsupported permissionDecision:allow`；合法 `deny` 仍会阻止真实冲突写入。
- 构建、生成和格式化等没有可静态证明目标的命令不再无意义地启动 PowerShell AST 子进程，避免 Windows CI 或低性能电脑因冷启动超时而产生错误的路径诊断；真实变化仍由 PostToolUse Git 差异归因。
- 修复成员电脑能在 UGit 使用项目、但 Agent Hub 独立进程报 `spawn git ENOENT` 的问题。Git 缺失、PATH 无效或权限不足时会显示明确的已检查来源和处理建议。
- 修复异常关机或网络中断后只能看到通用 `cannot reactivate` 错误的问题。恢复原因现在区分服务不可达、请求超时、凭证失效、成员移除、房间解散、版本不兼容、无效响应和本地恢复记录异常。
- 明确不可恢复的凭证、成员、房间或版本错误不再触发无意义的后台普通重试；网络类错误继续使用最长五分钟的指数退避。

## 界面优化

- 未领取租期的实时会话行不再重复显示 Codex Session ID、Hub Session ID、当前 Turn ID，也不再显示包含完整 ID 的自动生成会话占位文案。
- 三类会话 ID、缩略显示和复制入口统一保留在领取租期后的任务卡中；实时会话仍显示成员、客户端、分支、`activityEpoch` 和真实任务描述，历史调用归因继续保留 Turn ID。
- 恢复中的房间卡提供中文处理建议。网络错误提示检查房主服务、IP、端口、局域网和防火墙；凭证失效、成员移除或房间解散时引导联系房主或从本机安全移除旧连接后重新加入。

## 兼容性与升级

- 应用版本为 `0.2.8`，protocol 保持 `2`，数据库 schema 保持 `6`，最低来源 protocol/schema 保持 `1/2`。
- v0.2.7 用户可通过应用内更新升级，无需重新加入房间，也不会删除房间数据库、连接凭证、Hook、MCP 配置、会话、租约或审计数据。
- `pause-retry.json` 继续使用兼容的版本 1 格式，只增加可选诊断字段；本版本不增加远程 REST/MCP 字段或数据库字段。
- 旧清理完成前连接保持禁用，不启动 Hook/MCP、扫描器或接入调度，也不会创建新 Hub Session 或 Agent 租约。本版本不提供忽略清理后强制进入，也不要求手工删除恢复文件。
- 动态清理只处理明确白名单中的低价值历史活动，并保护当前有效租约、未关闭或正在收尾的会话、待处理释放申请及关联活动。清理不生成新活动，也不在普通请求期间执行全量 `VACUUM`。
- 纯监测模式继续放行普通写入；租约领取、冲突判断、审计、PostToolUse 归因和人工租约生命周期保持不变。

## 已验证

- 两套 TypeScript 检查、64 个测试文件共 636 项串行测试、Vite 客户端与 Node 服务端生产构建及 `git diff --check` 通过。
- 自动化覆盖桌面代理范围事件路由、Hook 放行提示、PATH/标准 Git/UGit 内置 Git 发现、Git 缺失诊断，以及纯监测放行和真实冲突拒绝。
- 动态清理测试覆盖 30/90 天保留策略、有效租约/活动会话/待处理申请保护、跨房间隔离、分批事务、重复执行和失败降级。
- 重启恢复测试覆盖旧版恢复文件、失败分类、固定请求身份、立即重试去重、跨房间隔离、等待期间接入关闭和清理完成后的正式激活。
- 本地界面在 1264x710 桌面与 390x844 窄屏视口无横向溢出；实时会话行不重复显示 ID，租期任务卡继续保留 ID，恢复面板文案和按钮结构通过静态渲染测试。
- Windows 标签流水线会在创建 Draft Release 前再次执行版本/说明门禁、两套 TypeScript 检查、串行全量测试、NSIS 打包、更新恢复探针、打包数据库迁移探针、签名更新清单和资产校验。
