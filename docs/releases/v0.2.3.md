# Agent Hub v0.2.3

v0.2.3 重点改进 Codex 回合结束后的自动租约释放、会话收尾可靠性和安装升级后的配置恢复。自动租约现在会在任务改动已提交或完全撤销后释放；尚未提交时继续保护到现有 TTL，同时不影响手动普通或独占租约。

## 新增内容

### Stop 与提交完成检测

- 新增无 matcher、`timeout = 3` 的 `Stop` Hook。Codex 每轮回答结束后，Agent Hub 会保存 completion operation ID、turn ID、activity epoch、自动租约和本轮归因路径，再进行限时检查；Hook 始终向 Codex 返回 `{"continue":true}`。
- 自动租约新增 `working` 和 `awaiting_commit` 阶段。进入 `awaiting_commit` 后停止心跳续期；归因改动已经完整进入本地分支 HEAD，或已经完全撤销、没有净改动时，自动租约立即释放。
- 仍有未提交改动时，自动租约继续保护到房间当前 TTL。桌面后台每 15 秒只检查等待提交的任务，检测到外部终端完成提交后可提前释放。
- 完整性按该 Codex 任务已经归因的路径判断。无关提交、部分提交、提交后继续修改、分支变化、路径截断或证据不完整都不会触发提前释放。
- Agent Hub 只检测本地提交，不执行 `git commit`，不要求 `push`，也不限制提交作者。手动普通和手动独占租约不参与这套自动释放流程。

### 持久化会话收尾

- 会话增加 `finalizing` 状态，最终 Git 证据、验证记录、功能记忆和会话关闭由桌面后台持久队列继续处理，不再全部挤在 Codex 的三秒结束窗口内。
- 最终处理使用 `finalizationId` 和 operation ID 幂等执行；桌面重启、网络重试、重复 Hook 或响应丢失不会重复生成最终扫描和功能修订。
- 正常桌面退出遇到未到期完成任务时，保留该连接的本地队列、会话和远端租约，重启后继续检查提交。显式暂停、退出房间或删除连接仍按原语义完整清理。

### 安装后的 Codex 配置对账

- 安装版桌面端启动后会检查曾经明确安装过 Codex 接入的连接，自动补回缺失的 MCP 和五类受管 Hook，并替换旧 runner、错误参数及旧受管处理器。
- 连接记录增加三态安装意图，区分旧版本未知、明确安装和明确不安装；从未授权或已经明确移除的连接不会被擅自写回。
- 启动、手动安装、删除房间和桌面更新共用串行生命周期队列；配置合并检测并发修改，最多重读重合并三次后再原子替换。
- 用户自定义 Hook、其他 MCP 和无法确认归属的相似配置会保留。TOML 损坏或不可写时记录警告并等待下次重试，不阻断应用启动健康确认。

## 问题修复

- 修复 Codex 回合已经结束，但自动租约只能等待心跳或 TTL、无法在提交完成后及时释放的问题。
- 修复租约已经到期后，“当前被保护的系统”仍混入历史扫描结果的问题。实时保护现在只来自有效租约；Agent 实时活动、等待提交保护和历史记录分别显示。
- 修复 `SessionEnd timeout = 60` 超出 Codex 三秒上限，导致最终扫描、功能记忆或会话关闭可能被中断的问题。受管 `SessionEnd` 现在固定为 3 秒并快速排队。
- 修复同一成员、房间和 Codex session ID 在本地状态丢失后可能创建重复 Hub 会话的问题；schema 4 迁移会保守归并已有重复会话。
- 修复旧完成检查晚于新一轮写入、恢复响应丢失或网络重试时可能错误操作新租约的竞态；恢复与释放均受 activity epoch 和 operation ID 围栏保护。
- 修复桌面正常退出会删除等待提交队列，以及单个损坏队列条目阻塞其他健康任务的问题。
- 修复客户端时钟偏差可能让有效租约倒计时提前消失的问题；界面使用服务端 `generatedAt` 校准租约时间。

## 兼容性与升级

- 应用版本：`0.2.3`
- 协议版本：1
- 数据库 schema：4
- 最低可读取来源 schema：2

schema 4 为会话最终处理、Codex session 身份、activity epoch、自动租约阶段和幂等操作增加结构化字段及索引。schema 3 房间数据库会在事务中原位迁移；新版本启动前仍应保留更新恢复备份。旧客户端不能继续打开已经迁移到 schema 4 的房间数据库。

已安装 v0.2.2 的用户可以使用应用内更新。v0.2.0 和 v0.2.1 的旧更新器存在 `app.asar` 恢复备份缺陷，不能依靠旧版一键更新；这些用户需要手动运行 v0.2.2 或更新版本的 Setup，在原安装目录覆盖安装，不要先卸载或删除 Agent Hub 用户数据。

升级后，Agent Hub 会在后台校正已经授权的受管 Codex 配置。稳定 Hook launcher 路径、用户 Hook、非 Agent Hub MCP、房间数据库、连接记录和 DPAPI 凭证应保持不变；配置确实发生变化时需要重启 Codex。
