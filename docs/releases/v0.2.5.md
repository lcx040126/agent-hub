# Agent Hub v0.2.5

v0.2.5 修复新 Codex 任务首次写入被旧状态阻塞，以及房间正常时仪表盘误报断开的问题，并加强多任务租约和后台收尾的并发安全。

## 新增内容

- 新增受管 `UserPromptSubmit` Hook，在每次提示提交时登记真实 turn，避免首次写入沿用会话启动时的回退状态。
- 仪表盘为大数据区段返回真实总数和“暂未完整刷新”状态，完整证据继续通过专用接口按需读取。

## 问题修复

- 同一 Codex 任务重新打开时，新旧 generation 完全隔离，旧任务收尾不会阻塞、删除或复活新任务状态。
- 同一成员的重叠自动租约按先到先得处理，后来的会话等待现有持有者，不再形成反向阻塞。
- `SessionEnd` 与 `TurnCompletion` 队列支持并发合并、持久化重试和版本校验，迟到的旧证据不会覆盖新状态。
- 仪表盘不再把累积扫描详情塞进周期轮询；响应超过容量或部分截断时不会误报为房间离线。
- 桌面应用以全部连接暂停状态启动后，重新激活房间会自动恢复扫描、Codex 心跳和交接提醒，无需重启 Agent Hub。

## 兼容性与升级

- 应用版本：`0.2.5`；协议版本：1；数据库 schema：5；最低来源 schema：2。
- v0.2.2、健康的 v0.2.3 和 v0.2.4 可使用应用内更新。v0.2.0、v0.2.1 和无法启动的 v0.2.3 需运行 v0.2.5 Setup 覆盖原安装目录。
- 升级会保留房间、成员、连接、凭证、租约、扫描和功能记忆。不要先卸载 Agent Hub，也不要删除 `%APPDATA%\agent-hub`。
- 受管 Hook 增加到六类；若接入配置发生变化，请按界面提示重启 Codex。
